## ✨ Apa itu STORIQ?

STORIQ adalah **Content Repurposing Engine gratis** yang membantu siapa saja mengubah satu ide menjadi berbagai format konten — semuanya berbasis framework storytelling yang terstruktur.

> *"Tools ini bukan tentang menggantikan AI. Tapi membantu kamu berpikir lebih baik sebelum menghasilkan."*  
> — Andre Wahyu Hermawan

## 🎯 Cara Kerja

```
Ide → Framework → Story Blueprint → Generate → Content Atoms → Repurpose
```

### 6 Langkah Mudah

1. **💡 Masukkan Ide** — Tulis topik, target audiens, tujuan, dan tone konten
2. **🧭 Pilih Framework** — STORIQ 10 Elemen, The Hero's Journey, StoryBrand, Pixar's Spine, dll.
3. **📐 Buat Story Blueprint** — Dapatkan struktur cerita yang jelas dan terarah
4. **⚡ Generate Konten** — AI menghasilkan konten berbasis storytelling
5. **🧩 Pecah ke Content Atoms** — Artikel dipecah jadi hook, insight, quote, CTA, dll
6. **🔄 Repurpose** — Generate berbagai format untuk platform yang kamu inginkan

### Dua Mode Generation

| Mode 1: AI API (Otomatis) | Mode 2: Prompt Generator (Manual) |
|---|---|
| Masukkan API key sendiri (BYOK) | Tanpa perlu API key |
| Pilih OpenAI, Gemini, atau Groq | STORIQ generate prompt terstruktur |
| Generate otomatis langsung di STORIQ | Copy, paste ke ChatGPT/Gemini/Claude |
| Streaming output real-time | Tempel hasilnya kembali ke STORIQ |

## 🧠 STORIQ Framework

STORIQ bukan sekadar AI writer. Di baliknya ada **10 Elemen Framework** yang menggabungkan storytelling, copywriting, psychology, dan conversion:

1. **Context** — Memahami dunia customer
2. **Character** — Customer sebagai protagonis
3. **Conflict** — Menunjukkan gap yang nyata
4. **Desire** — Menggambarkan masa depan lebih baik
5. **Discovery** — Membuka perspektif baru
6. **Mechanism** — Menjelaskan cara kerja solusi
7. **Proof** — Memberikan bukti nyata
8. **Transformation** — Menunjukkan perubahan before → after
9. **Risk Reduction** — Mengurangi persepsi risiko
10. **Action** — Memberikan langkah berikutnya

## 🛠️ Tech Stack

| Layer | Teknologi |
|---|---|
| Framework | [Astro.js](https://astro.build/) v5 (Static Site Generator) |
| Styling | [Tailwind CSS](https://tailwindcss.com/) v4 |
| Client-Side | Vanilla JavaScript (zero dependencies) |
| Hosting | [GitHub Pages](https://pages.github.com/) |
| CI/CD | GitHub Actions ([withastro/action](https://github.com/withastro/action)) |

### Arsitektur

```
┌──────────────┐     ┌────────────────┐     ┌─────────────────┐
│   GitHub     │────▶│  GitHub        │────▶│  GitHub Pages   │
│   Repository │     │  Actions       │     │  (Static Host)  │
│   (Source)   │     │  (Astro Build) │     │  CDN Global     │
└──────────────┘     └────────────────┘     └─────────────────┘

Browser (Client-Side):
┌────────────────────────────────────────────────┐
│  User Input (Topik, Audience, Tone)            │
│         ↓                                       │
│  STORIQ Prompt Engine                           │
│         ↓                                       │
│  Mode 1: AI API ──── atau ──── Mode 2: Prompt  │
│  (fetch → Gemini/Groq)    (Copy → ChatGPT)     │
│         ↓                                       │
│  Output: Blog, Carousel, Caption, dll           │
│  💾 localStorage: API keys (never leaves browser)│
└────────────────────────────────────────────────┘
```

## 💻 Development

Untuk menjalankan STORIQ secara lokal:

```bash
# Clone repository
git clone https://github.com/andrean-lp/storiq.git
cd storiq

# Install dependencies
npm install

# Jalankan development server
npm run dev

# Build untuk production
npm run build

# Preview hasil build
npm run preview
```

**Struktur Project:**
```
storiq/
├── .github/workflows/deploy.yml   # Auto deploy ke GitHub Pages
├── public/                         # Static assets
├── src/
│   ├── components/                 # Astro components (Header, Footer)
│   ├── data/                       # JSON data (API providers, etc)
│   ├── layouts/                    # Base layout
│   ├── pages/                      # Pages (index, generator, framework, panduan, tentang)
│   ├── scripts/                    # Vanilla JS (AI client, prompts, storage)

├── astro.config.mjs
├── CLAUDE.md                       # AI coding context
├── LICENSE
├── package.json

```
